**新工程必须遵守的规则**（旧版的坑）：

| 规则 | 说明 |
|---|---|
| 路径全小写 | 旧版 `Img/` 与 `img/` 混用 10 处，非 Windows 平台必崩（GDD B3） |
| 禁止中文文件名 | 现有 `人物右.png`、`宝石.png` 等中文名需**重命名**（见 §4 命名规范），避免打包/跨平台编码问题 |
| 一份 `manifest.json` | 每个素材记录 `路径/尺寸/大小/md5/license/source`，缺 license 不得入库 |
| 运行时 `convert_alpha()` 一次并缓存 | 禁止循环内重复 `image.load` |

## 4. 命名规范（新工程强制）

旧版中文文件名在打包/跨平台时易出问题，统一改为**小写英文 + 下划线**：

```
img/heroes/{hero}/{state}[_{dir}][_{frame}].png
例：img/heroes/archer/idle_r.png
    img/heroes/archer/run_r_01.png    （帧号 2 位补零）
    img/heroes/brick/cast_a_r.png

img/enemies/{type}_{state}_{dir}.png
例：img/enemies/patrol_r.png
    img/enemies/boss_hurt.png

img/tiles/{tile_name}.png
例：img/tiles/grass.png      （原 墙.png）
    img/tiles/brick.png      （原 墙壁999.png）
    img/tiles/spike.png      （原 刺.png）
    img/tiles/crate.png      （原 纸箱复制.png）

img/items/{name}.png
例：img/items/gem_green.png  （原 宝石.png）
    img/items/gem_yellow.png （原 宝石2.png）
    img/items/portal_blue.png

img/fx/{effect}[_{frame}].png
img/ui/btn_{state}.png
wav/sfx/{action}.wav
font/{family}.ttf
```

**迁移对照表**（旧名 → 新名）需完整记录在 `docs/ASSET_MIGRATION.md`，避免工程找不到文件。
